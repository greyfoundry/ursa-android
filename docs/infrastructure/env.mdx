## what this is

Environment and local machine setup needed to build and run URSA. There are no
app runtime env vars (it's a client with no backend); this covers the build
toolchain and the local dev servers.

## technical map

**build env**
- `JAVA_HOME` → Android Studio's bundled JBR:
  `C:/Program Files/Android/Android Studio/jbr`
- Android SDK platform 37 and build-tools 37.0.0.
- A gitignored `local.properties` points `sdk.dir` at the machine's Android SDK.
- Android Studio's bundled JBR 21 runs the build; source and bytecode target 17.

**dev servers (Docker)**
- Use an official `louislam/uptime-kuma` image on host port `3001`. The current
  compatibility baseline is tag `2.5.5`; create disposable QA credentials during
  setup or pass them through local environment variables.
- `ntfy-dev` → `binwiederhier/ntfy` on `:8080` (UnifiedPush distributor test).
- From emulator reach the host at `10.0.2.2`; Kuma reaches ntfy at
  `host.docker.internal:8080`.

## gotchas

- `local.properties` must escape the Windows drive colon for lint:
  `sdk.dir=C\:/Users/User/AppData/Local/Android/Sdk`. Gradle accepts the
  unescaped form but Android lint tasks fail on it.
- No secrets live in the repo. Kuma JWTs are stored encrypted on-device only.
