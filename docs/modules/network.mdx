## what this is

Everything that talks to a Kuma server. The live connection (real-time monitor
status, heartbeats, certs, pause/resume, login) runs over Socket.IO; the public
status-page viewer uses plain REST. All of Kuma's wire weirdness is contained
here so the rest of the app sees clean domain models.

## technical map

**file paths**
- `app/src/main/java/dev/astoris/ursa/core/network/KumaClient.kt` - one Socket.IO
  connection per server; auth, event wiring, pause/resume, getBeats.
- `.../core/network/KumaParse.kt` - pure wire→domain parsing (kotlinx, no Android
  org.json) so it is JVM-unit-testable.
- `.../core/network/StatusPageClient.kt` - Ktor client for public status pages.

**exports**
- `KumaClient(baseUrl)` - `connect()`, `login(u,p,token)`, `loginByToken(jwt)`,
  `setup()`, `pauseMonitor(id)`, `resumeMonitor(id)`, `getBeats(id,hours)`,
  `disconnect()`. Flows: `state`, `monitors`, `heartbeats`, `certs`.
- `KumaParse` - `monitorList`, `monitor`, `heartbeat`, `beatRow(s)`, `cert`, `tags`.
- `StatusPageClient.fetch(baseUrl, slug): StatusPageView`.

**depends on**
- `io.socket:socket.io-client`, `io.ktor:ktor-client-*`, kotlinx-serialization.
- `data/model` - the domain types it produces.

**imported by**
- `data/repository/MonitorRepository` (live client) and `ui/UrsaViewModel`
  (status-page client).

## gotchas

- Positional events (`avgPing`, `uptime`, `certInfo`) are read from `args[]`
  directly; object events go through `jsonAt()` → kotlinx → `KumaParse`.
- `heartbeat` event is camelCase; `getMonitorBeats` rows are snake_case - two
  parse paths (`heartbeat` vs `beatRow`). Covered by `KumaParseTest`.
- `emitAck` buffers if the socket is mid-connect (Socket.IO queues emits) - safe,
  but the ack resolves only after the server replies.
- Reconnect: `KumaClient` keeps the JWT and silently re-emits `loginByToken` on
  every `EVENT_CONNECT`, so a dropped socket re-authenticates itself. `disconnect()`
  clears the JWT.
- Self-signed TLS: `KumaClient(url, insecure=true)` sets Socket.IO's
  `callFactory`/`webSocketFactory` to `TlsTrust.insecureClient()`;
  `StatusPageClient` uses Ktor OkHttp `preconfigured`. Trust-all is opt-in only.
- The UI routes on the ViewModel's `hasSession`, not raw `state`, so transient
  disconnects don't bounce to login.
