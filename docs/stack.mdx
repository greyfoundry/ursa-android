## what this is

The full technology stack and versions URSA is built on, with the reasoning
behind the non-obvious choices. If a version here disagrees with what the build
actually resolves, the build wins - update this file.

## technical map

**toolchain (verified building on this machine 2026-07-03)**
- Kotlin **2.4.0** (pinned via root `buildscript` classpath - see gotchas)
- Jetpack Compose - BOM **2026.06.01** (core 1.11.4, material3 1.4.0)
- Android Gradle Plugin **9.2.0**, Gradle **9.4.1**
- compileSdk **36** (android-37 platform not installed locally), minSdk **26**,
  targetSdk 36
- JDK: build runs on Android Studio's bundled JBR 21, targets Java/Kotlin 17
- SDK build-tools 36.1.0 / 37.0.0; platform android-36.1

**planned M1 dependencies (not yet wired - Phase B)**

## gotchas

- **AGP 9 has built-in Kotlin.** Do NOT apply `org.jetbrains.kotlin.android` (it
  errors). Keep `org.jetbrains.kotlin.plugin.compose`. AGP bundles an older KGP,
  so Kotlin 2.4.0 is pinned in root `build.gradle.kts`:
  `buildscript { dependencies { classpath("org.jetbrains.kotlin:kotlin-gradle-plugin:2.4.0") } }`.
- The `android { compilerOptions { } }` DSL from AGP 9.0 notes is not resolvable
  on 9.2 - omit explicit Kotlin `jvmTarget`; AGP aligns it to `compileOptions`.
- Kotlin 2.4 rejects Gradle 9.1; the wrapper was pointed at 9.4.1 deliberately.
- Build command: `JAVA_HOME` = JBR, then `./gradlew.bat assembleDebug --no-daemon`.
