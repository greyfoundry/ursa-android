## what this is

The completed native-depth milestone: Android and Wear capabilities that a browser
tab cannot provide while URSA remains a direct client with no hosted backend.

## delivered

1. Encrypted per-server offline monitor snapshots with explicit freshness and live
   reconciliation.
2. Optional biometric/device-credential app lock backed by a Keystore-bound proof.
3. Explicit immutable notification actions and non-exported action receivers.
4. Local certificate-expiry reminders from encrypted cached certificate metadata.
5. Exact-size Glance widgets with encrypted per-instance private/public sources,
   selected rows, manual refresh, freshness, and strict scoped deep links.
6. Quick Settings fleet-status tile.
7. Launcher shortcuts and validated in-app routes.
8. Extracted UI string resources ready for community translations.
9. Optional always-on glance display with power/burn-in disclosure and visible exit.
10. Wear OS dashboard, monitor detail, tile, SHORT_TEXT/LONG_TEXT complications,
    and optional confirmed same-signed private session pairing.

## boundaries

- Cached data accelerates first paint; it is not a background synchronization engine.
- Widget and notification routes resolve only saved local sources and never embed a
  server URL, token, or access header.
- The default/F-Droid phone build omits Play Services. Only the GitHub phone build
  enables the optional Wear Data Layer sender; the separate Wear APK is distributed
  through GitHub Releases.
- Self-signed private sessions are not paired because session-lifetime certificate
  trust cannot safely transfer to the watch.
- Widgets remain a secondary convenience. Issue-driven reliability work takes
  precedence over launcher-specific polish.

## verification

Logic, parser, security, widget-data, and Wear tests cover bounded inputs and route
validation. Android 17 phone QA covers list/detail, widgets, tile, shortcuts, deep
links, and glance mode. Android 16 Wear QA covers setup, live public dashboard/detail,
tile/complication registration, encrypted private session storage, and actions. A
real paired-watch Data Layer transfer remains the only hardware-specific caveat.
