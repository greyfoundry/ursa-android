## what this is

URSA is a native Android app for **Uptime Kuma** - a popular self-hosted uptime
monitor. It lets someone watch their servers/websites from their phone: see which
monitors are up or down in real time, read history and TLS-cert info, pause or
resume checks, and receive a push notification the moment something goes down.
Android has lacked a solid Uptime Kuma client for years; URSA fills that gap, and
its headline feature is push notifications that need no paid relay server.

Read this file first every session. It is the map. Do not scan the repo - go
straight to the room you need via the layer map in `docs/architecture/index.mdx`
and the module docs under `docs/modules/`.

## gotchas

- The Uptime Kuma socket API is **internal/unstable**. Several event payloads are
  positional multi-arg emits, not objects - see `docs/references/uptime-kuma-api.mdx`
  (verified live, do not trust the upstream wiki blindly).
- Public artifacts contain only project-relevant information and credited
  contributors. Omit private workflow provenance and co-author trailers.
